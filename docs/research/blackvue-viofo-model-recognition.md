# BlackVue and VIOFO Model Recognition Catalog

Updated 2026-08-13 from the manufacturers' current collections and manuals.
This catalog offers exact-model hints, not automatic profile support.

## Evidence Boundary

BlackVue keeps its existing exact config-file recognition. Its manual index
also confirms current DR970X, DR770X, DR900X, DR750X, DR590X, K-series, and
Elite-series families.

VIOFO now accepts a model-coded root firmware filename (`.bin`, `.fw`, or
`.zip`) as a weak catalog hint. It does not select a profile, because a
firmware file can be left on a card. A card without a trained profile remains
on the generic read-only importer.

## Added VIOFO Configurations

The current VIOFO collection/manual pages add catalog entries for A119 V3,
MT1, A329SW, A329TC, A329TW, A329WW, A229 Ultra-W, A229 Pro-W, A229 Plus-W,
and A229 Pro Tele. Their documented channel roles distinguish waterproof,
telephoto, interior, and heavy-duty dual-rear variants without assuming their
card filenames or folders.

## Added BlackVue Configurations

The BlackVue manual index adds exact catalog variants for DR970X 2CH LTE Plus
II, DR970X 2CH IR Plus, DR970X Box 2CH Plus, DR750X 3CH Plus, and DR750X 2CH
LTE Plus. These remain catalog-only unless their own card evidence matches a
bundled profile.
