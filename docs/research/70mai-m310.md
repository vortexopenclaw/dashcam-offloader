# 70mai M310 — Research Notes

## Sources

- Official manual: [70maiDashCam_M310_UserManual.pdf](https://cdn-www.70mai.com/instructions/70maiDashCam_M310_UserManual.pdf) (V2025.12, multilingual)
- NAS-archived footage (driving and parking samples)
- Real microSD card scan

## Manufacturer

70mai Co., Ltd., Shanghai, China. M310 is an entry-level single-channel front dashcam
with Wi-Fi and voice control. App required for live view and settings adjustment.

## Filename Pattern

Pattern: `[MODE]YYYYMMDD-HHMMSS-SEQUENCE.mp4`

| Field | Format | Example |
|---|---|---|
| Mode prefix | 2 uppercase letters | `NO`, `LA` |
| Date | `YYYYMMDD` | `YYYYMMDD` |
| Separator | `-` | |
| Time | `HHMMSS` | `HHMMSS` |
| Separator | `-` | |
| Sequence | Zero-padded integer (6 digits) | `000001` |
| Extension | `.mp4` (lowercase) | |

Full example: `NO20240101-120000-000001.mp4`

### Mode Prefixes

| Prefix | Mode | Folder | Confirmed |
|---|---|---|---|
| `NO` | Normal/continuous recording | `Normal/` | ✅ card scan |
| `NO` | Normal-sensitivity parking | `Parking/` | ✅ NAS sample |
| `LA` | Time-lapse parking mode | `Lapse/` | ✅ NAS sample |
| `EV` | Event/locked clip | `Event/` | ❓ inferred; no sample |

### Key Differences from VIOFO

- **Lowercase `.mp4`** vs VIOFO uppercase `.MP4`
- **Date-hyphen-time** format vs VIOFO `YYYY_MMDD_HHMMSS` with underscores
- **Mode prefix at start** vs VIOFO channel/sequence at end
- **No channel letter** — single camera only
- **No `DCIM/` hierarchy** — folders are at the root of the card

## Sequence Numbers

- Scope: global across all modes and folders
- Padding: 6 digits zero-padded
- Counter does not reset on card format — confirmed global monotonic across modes

## Resolution and Codec

| Channel | Resolution | Codec | FPS | Segment |
|---|---|---|---|---|
| Front | 2304×1296 | HEVC (H.265) | 30 | 60 s |

Manual specification: "Resolution: 2304 × 1296". Confirmed by ffprobe on NAS samples.
Single-channel camera — no rear or interior channel.

## OSD Analysis

The M310 burns **date/time** into the bottom of every frame in the format:
```
MM-DD-YYYY HH:MM:SS | [additional data]
```

**Key finding**: The OSD does **not** embed the model name. This is fundamentally
different from VIOFO cameras (which show "VIOFO A229 Pro" etc.) and means OCR-based
model identification is not possible for 70mai cameras using this approach.

The `|` separator is followed by what may be GPS speed or another data field. The date
format `MM-DD-YYYY` matches North American convention.

Daytime footage with complex scenes produced OCR noise because OSD text blends with
high-contrast road/sky backgrounds. Night footage gave clean OCR reads.

## Folder Structure (Confirmed from Card Scan)

All five folders confirmed present on real card:

| Folder | Contents | Status on scanned card |
|---|---|---|
| `Normal/` | Loop recording (NO prefix, driving) | Populated |
| `Parking/` | Normal-sensitivity parking (NO prefix) | Empty |
| `Lapse/` | Time-lapse parking (LA prefix) | Empty |
| `Event/` | Locked/emergency clips | Empty |
| `Photo/` | Snapshots | Empty |

Note: The initial profile (built from NAS footage alone) incorrectly assumed
time-lapse clips go to `Parking/` and emergency clips go to `Emergency/`. The card
scan confirmed the correct folder names: `Lapse/` for time-lapse, `Event/` for
emergency, and `Parking/` for normal-sensitivity parking only.

## Card Marker Files

Two categories of hidden files confirmed on card:

**Root-level:**
- `.formated` — created by camera when card is formatted in-camera. Note unusual
  spelling "formated" (single t). Serves as a reliable 70mai-family signal.

**Per-folder:**
- `.sstar.format` — present in each of the five recording folders. Likely a folder
  initialization marker written by firmware. Purpose not documented in manual.

## Detection Strategy

Strongest approach (in priority order):

1. **`.formated` root marker** — spelling is a strong 70mai fingerprint
2. **Filename pattern** `^(NO|LA|EV)\d{8}-\d{6}-\d+\.mp4$` with lowercase extension
3. **Folder set** `Normal/`, `Parking/`, `Lapse/`, `Event/`, `Photo/` with `.sstar.format`
4. **Resolution** 2304×1296 HEVC 30fps (supporting, not unique)
5. **OSD** — negative signal only (rules out VIOFO/Thinkware families)

Within 70mai's lineup, different models may share this filename scheme and folder
structure. The M310 is 1CH — multi-channel files in this pattern would suggest a
different 70mai model.
