# Vantrue Model Recognition Catalog

Updated 2026-08-13 from Vantrue's official collection and manual/firmware
index. This catalog is for exact identity hints, not a claim of trained card
support.

## Recognition Boundary

Existing Vantrue recognition reads a model-coded `GPS/*_Settings.ini` file.
Those settings filenames are exact model evidence and can identify a known
catalog model while retaining the generic importer when no profile exists.
The app does not infer a profile from a manual listing, product name, or
shared Vantrue folder shape.

## Newly Added Catalog Models

The manual/firmware index contributed P2, E2 Pro, S1 Pro Max, N1 Pro, N2,
X4S, X4, T3, T2, M3, M2, VP05, VP03, and VP01. Where the official source did
not clearly establish channel configuration, these entries deliberately omit
channel and resolution claims until a card scan is received.

Previously cataloged current families include Nexus 5/5S, Nexus 4 Pro/N4 Pro
S/N4 S, N2X, E360, Element E1/E2/E3, S1/S1 Pro/S2, and Falcon 1.
