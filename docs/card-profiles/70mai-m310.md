# 70mai M310 Card Profile

**Make:** 70mai  
**Model:** M310  
**Channels:** 1 (front only)  
**Resolution:** 2304×1296  
**Codec:** HEVC (H.265)  
**Source:** Private archive sample + official manual + real card scan

---

## Filename Format

```
[MODE]YYYYMMDD-HHMMSS-SEQUENCE.mp4
```

| Field | Description | Example |
|---|---|---|
| `MODE` | 2-letter uppercase recording mode | `NO`, `LA` |
| `YYYYMMDD` | Recording date | `20260206` |
| `-` | Separator | |
| `HHMMSS` | Recording time (24h) | `141441` |
| `-` | Separator | |
| `SEQUENCE` | Global monotonic counter, zero-padded 6 digits | `000062` |
| `.mp4` | Lowercase extension | |

**Examples:**
- `NO20260206-141441-000062.mp4` — normal recording
- `LA20260209-170336-000826.mp4` — time-lapse parking

## Recording Modes

| Prefix | Mode | Folder |
|---|---|---|
| `NO` | Normal continuous loop recording | `Normal/` |
| `NO` | Normal-sensitivity parking mode | `Parking/` |
| `LA` | Time-lapse parking mode | `Lapse/` |
| `EV` | Event/locked clip *(prefix inferred — no sample available)* | `Event/` |

Note: `NO` prefix is shared between normal driving recordings and normal-sensitivity
parking mode recordings. The folder (`Normal/` vs `Parking/`) distinguishes them.

## Card Marker Files

| Path | Description |
|---|---|
| `.formated` | Root-level file created when card is formatted in-camera. Note spelling ("formated" not "formatted"). Strong 70mai-family signal. |
| `[folder]/.sstar.format` | Present in each recording folder. Likely a folder initialization marker. |

## Sequence Numbers

The sequence counter is **global across all modes and folders** — normal driving,
normal parking, and time-lapse parking all share one incrementing counter. Zero-padded
to 6 digits. Card scan confirmed sequences 489–583+ on a single 2026-02-14 session.

## OSD (On-Screen Display)

The M310 burns **date and time** into the bottom of every frame:

```
MM-DD-YYYY HH:MM:SS | [additional data]
```

**The OSD does not show the model name.** This means the OCR-based model
identification used for VIOFO cameras cannot be applied here.

## Detection

Primary signals, in order of reliability:

1. **`.formated` root file** — 70mai-family card marker (unusual spelling is a strong signal)
2. **Filename pattern** `^(NO|LA|EV)\d{8}-\d{6}-\d+\.mp4$` — mode prefix + date-hyphen-time
3. **Folder set** `Normal/`, `Parking/`, `Lapse/`, `Event/`, `Photo/` with `.sstar.format` in each
4. **File extension** lowercase `.mp4` (rules out VIOFO)
5. **Resolution** 2304×1296 HEVC 30fps (supporting)
