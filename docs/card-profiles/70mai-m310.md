# 70mai M310 Card Profile

**Make:** 70mai  
**Model:** M310  
**Channels:** 1 (front only)  
**Resolution:** 2304×1296  
**Codec:** HEVC (H.265)  
**Source:** NAS-archived footage + official manual

---

## Filename Format

```
[MODE]YYYYMMDD-HHMMSS-SEQUENCE.mp4
```

| Field | Description | Example |
|---|---|---|
| `MODE` | 2-letter uppercase recording mode | `NO`, `LA` |
| `YYYYMMDD` | Recording date | `20260206` |
| `-` | Separator | |
| `HHMMSS` | Recording time (24h) | `141441` |
| `-` | Separator | |
| `SEQUENCE` | Global monotonic counter, zero-padded 6 digits | `000062` |
| `.mp4` | Lowercase extension | |

**Examples:**
- `NO20260206-141441-000062.mp4` — normal recording
- `LA20260209-170336-000826.mp4` — time-lapse parking

## Recording Modes

| Prefix | Mode |
|---|---|
| `NO` | Normal continuous loop recording |
| `LA` | Time-lapse parking mode |
| `EM` | Emergency/locked clip *(inferred from manual — not confirmed from footage)* |

`NO` prefix is used for both normal driving recordings and normal-sensitivity parking
recordings. `LA` is used specifically for time-lapse parking.

## Folder Structure

> **Note:** Folder names are inferred from 70mai conventions. A direct card scan has
> not been performed. All folder-related information should be treated as approximate.

| Folder | Contents |
|---|---|
| `Normal/` | Loop recording clips from driving |
| `Parking/` | Parking mode clips (time-lapse and normal) |
| `Emergency/` | Locked clips from impact or voice command |

## Sequence Numbers

The sequence counter is **global across all modes** — normal and parking recordings
share a single incrementing counter. Zero-padded to 6 digits.

## OSD (On-Screen Display)

The M310 burns **date and time** into the bottom of every frame:

```
MM-DD-YYYY HH:MM:SS | [additional data]
```

**The OSD does not show the model name.** This means the OCR-based model
identification used for VIOFO cameras cannot be applied here.

## Detection

The filename pattern `^(NO|LA|EM)\d{8}-\d{6}-\d+\.mp4$` is the primary detection
signal. The lowercase `.mp4` extension (vs uppercase `.MP4` on VIOFO) provides a
quick filter. Combined with single-channel 2304×1296 HEVC resolution, this uniquely
identifies a 70mai camera in the M-series.
