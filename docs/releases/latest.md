# Dashcam Offloader 0.1.6

- Redesigned the main workflow around the actual decisions: choose a card and
  footage, choose a download folder, then review and download.
- Recording and file types now appear with the scanned card, not in a duplicate
  lower panel.
- Storage volumes can be hidden from Sources permanently and restored from the
  Sources sidebar when needed.
- Updates and feedback are tucked into the toolbar's More menu.
