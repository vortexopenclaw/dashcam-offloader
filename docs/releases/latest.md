# Dashcam Offloader 0.1.33

- Open **View All Issues…** from the card-health warning or the main card-health section to inspect every issue, not just the first five.
- Search affected timestamps, camera channels, filenames, and relative folders. Unmatched groups show the recordings that are present; empty or unreadable-file warnings retain their complete file lists.
- Reveal existing recordings in Finder, copy the full report, or save it outside the source card. Reports include private recording filenames and folders; review them before sharing. Saving never overwrites an existing file.
- Keep the warning compact, with complete evidence in the details screen. Search narrows the displayed evidence, while Copy and Save always include the full report.
- Distinguish potentially unmatched channels from confirmed recording loss. Exact timestamp and mode grouping can separate related recordings. Metadata readability checks are not full video decoding or proof of corruption.
- Preserve the existing grouping rules and read-only card inspection. This update improves visibility and wording; it does not establish the cause of an individual recording gap.
